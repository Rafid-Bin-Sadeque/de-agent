# {{name}} hub

This folder is the knowledge hub read by a Claude Code agent through the de-agent plugin.

- `de-agent.yaml`: sources to snapshot and the guard mode (secret references only, never values).
- `map.md`: always loaded at session start; one line per project; stays under the token budget.
- `domains/`: optional, one page per domain once the map gets big; each lists its projects.
- `projects/<name>.md`: one profile per project: purpose, layout, conventions, connections, gotchas.
- `integrations/<a>--<b>.md`: how two projects talk, for what code and snapshots cannot show.
- `conventions.md`: how things are built here.
- `status.md`: dated checks, work in progress and open issues; due rows are injected at session start.
- `platform/`: GENERATED by `dea snapshot`; never edit by hand.
- `.dea/`: local state (snapshots, search index, logs); git-ignored.

Commands: `dea snapshot`, `dea diff`, `dea find <term>`, `dea lint`, `dea doctor`.
Run `dea lint` in CI to keep budgets, links and frontmatter honest.
